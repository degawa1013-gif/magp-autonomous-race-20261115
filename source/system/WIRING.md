# 保存コードが期待する接続

これは**ソフトウェア側の接続期待値**であり、決勝時の現物配線が同一だったことを証明する回路図ではない。差し替えを案内する資料ではなく、復元時の照合表である。

|信号|大きいRaspberry Piの接続|コードの根拠|
|---|---|---|
|操舵サーボの信号|BCM GPIO19、物理35番|`legacy_pi_output.py` の `STEERING_GPIO=19`|
|ESCの細い信号|BCM GPIO12、物理32番|同 `THROTTLE_GPIO=12`|
|回転センサーDOUT|BCM GPIO17、物理11番|`robust_lane_failsafe.py` の `GPPIN_ENCODER=17`|
|GND|PiとESC・サーボ等の信号基準を共通化|開発時の接続試験と報告。物理39番が使用されたとの会話記録あり。コードでは電気的導通を検証しない|

実出力周期は両チャンネル50 Hzである。操舵中立1530 µs、ESC中立1531 µs、前進端1059 µs、後退端1980 µsをコードで使用する。GPIO13/18は12/19とPWMチャンネルを共有するため、出力アダプタは13/18のパッドを入力・プルなしへ設定する。

赤・黒線の最終的な分配、受信機の各段、センサー電源、ESC型番・モーター型番・ボード型番については、物理配線と電源仕様を別途確認する。過去には受信機給電やPico信号経路を複数回変更しているため、一つの途中写真を最終配線とみなさない。

この保存版の通常制御はPi直接出力である。PC側の無線観測用Pico 2 Wは別系統であり、この表へ制御用配線として追加しない。
