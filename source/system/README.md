## 処理の流れ

`robust_lane_failsafe.py` がPicamera2から320×240の画像を受け取り、動的白線抽出、鳥瞰変換、経路点追跡、画像誤差のPDと先読み補助を行う。`FastControlOutput` がDualSense操作と運転モードを仲裁し、`LegacyPiOutput` を通じてPiのPWMを更新する。同じプロセスが8000番ポートでWebとG2資材を提供する。

主要モジュール：

|ファイル|役割|
|---|---|
|`adaptive_white.py`|明度・彩度・床色との対比に基づく白色候補|
|`far_preview.py`、`steering_preview.py`|連結した白線の遠方観測と補助操舵|
|`return_damping.py`|十分に支持された直線収束時の小さな戻し補助|
|`curve_pace.py`|画像形状から自動前進出力率の上限を設定|
|`dualsense_control.py`|Linux入力イベント、モード・ギア・緊急停止の仲裁|
|`fast_control_output.py`|画像処理から独立した出力処理|
|`legacy_pi_output.py`|従来の論理デューティを50 HzのPWMパルスへ変換|
|`telemetry_hud.py`、`even_hud_dist/`|Web/Even G2への状態表示|
|`drive_capture.py`、`drive_capture_finalize.py`|容量上限付きの画像・マスク・指令記録|
|`wifi_monitor.py`、`bluetooth_monitor.py`|無線・入力関連の診断観測|

Pure Pursuit、Stanley、SLAM、ROSを採用した実装として説明しない。先読みは画像座標と指令出力率に基づく。PWM出力率は速度目標ではなく、ログの操舵値は実舵角の測定値ではない。

## 必要な実行環境

実機のインストール済みバージョン一覧は回収できていない。以下はimportと起動処理から確認できる依存であり、再現済みの固定バージョン環境を表すものではない。

|対象|確認できた必要条件|
|---|---|
|OS・Python|Raspberry PiのLinux、Python 3.10以上の構文を使用。正確な実機版は未確認|
|画像処理|NumPy、OpenCV（`cv2`）|
|カメラ|Picamera2、対応するlibcameraとカメラ構成|
|GPIO|pigpio Pythonモジュール、接続可能な`pigpiod`。ボード対応の事前確認が必要|
|ゲームパッド|Linux `/dev/input/event*` の読取権限。Pythonの追加evdevパッケージはimportしていない|

|ランチャー|Bash、`flock`、`pgrep`等。回収済みの補助と旧校正オプションは後述|

依存のインストール、Bluetoothペアリング、権限変更、OS設定変更は、この保存作業では行っていない。競技環境へ導入する際は、対応ボード、版、権限と物理的な停止手段を確認する。

## 起動ファイルの回収状況

既存の `run_with_g2.sh` と `run_with_logger.sh` は当日の内容のまま保存した。初回に参照できたコピーと34個のtar/zipでは欠けていた `status_csv_logger.py` は、その後に復帰した元の `rpi_system/` から無変更で回収して同じディレクトリへ追加した。由来とハッシュは `../RECOVERED_HELPERS_MANIFEST.json` にある。当日の配備補助と同じ版かは未確認であり、最初の25本のmanifestに含まれていたと扱わない。

オプションの `--rc-calibrate` が参照する校正コードと旧受信系の依存4本も回収したが、最終DualSense経路とは別に `../recovered_receiver_tools/` へ保存した。このオプションは現行ディレクトリからの利用を保証しない。推測による校正や受信系の再導入は行っていない。

主制御にはWeb/G2の静的資材配信と自動走行の診断記録が含まれる。別のパッケージ用起動補助を用意する場合は競技中の原本と区別する。補助を追加しても、実機の起動・物理的な動作を検証したことにはならない。

パッケージ作成では、実機を動かす起動・GPIOアクセス・無線接続を実行していない。

## 信号と校正値

`WIRING.md` に保存コードが期待する信号先をまとめた。実機の最終配線を撮影して復元した図ではない。

起動時の運転モードはSTOP/N、中立指令は操舵1530 µs、ESC1531 µsである。ただし白線喪失による知覚状態STOPと、運転者のSTOPモードは異なる。AUTO中の長期白線喪失では前進指令を残す実装がある。実車の停止判断をコード名から推測しない。

車輪換算は径0.06 m、36パルス/回転を仮定する。これらの独立した校正記録はない。実舵角、実軌跡、実速度と指令を分けて扱う。
